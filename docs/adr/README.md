# Architecture Decision Records

Short, dated records of decisions that span more than one workspace (`api/`, `ui/`, `host/`) or depend on external specs. Workspace-specific usage docs stay in each workspace's README.

- File name: `NNNN-kebab-case-title.md`, numbered in order. Never renumber.
- Sections, at minimum: Status, Context, Decision, Consequences / open risks, References.
- To change a decision, add a new ADR that supersedes the old one and update the old one's Status.
- Docs-only: no changeset needed (see `AGENT.md`).
